# New designs start by laying the lanes, in both modes

Every new design (from a venue template or a blank area) opens in Quick mode's step 1, "Lay the lanes", in Advanced mode as well as Quick, and the old starter loop is no longer used. There is no track to edit until the loop closes, and one starting path keeps the two modes consistent. Existing tracks open in step 2 because they already have points. Accepted by the Board (Yeti, 2026-11-05) in #44.
