# "1 · Lay the lanes" goes back only for a loop laid in this session

Going back from step 2 to step 1 reopens the loop from the squares it was laid with. The designer keeps those squares in the draft's `laid` field, which never reaches the file, so a track opened from the library has no squares to go back to: there the step is shown as plain text, not a button. Accepted by the Board (Yeti, 2026-11-05) in #48.
